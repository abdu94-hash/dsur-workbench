# DSUR Workbench

Companion tools, Word and Excel templates, and a fully worked mock DSUR for the Selim Medical Press manual on writing **Development Safety Update Reports** under ICH E2F.

**Author:** Dr. Hafez Selim, MD, PhD · **Publisher:** [Selim Medical Press](https://abdu94-hash.github.io/selim-medical-press/)

**[Open the free DSUR field guide](https://abdu94-hash.github.io/dsur-workbench/guide/)**: the point of every DSUR section, what its reviewer asks, how much detail each program stage needs, and the take-home messages and a self-check for each chapter.

All data are fictional. Word and Excel files download from each folder; the browser tools run online from GitHub Pages or offline from a downloaded copy.

## Tools

Single-file HTML tools that run in any modern browser, online or offline. Nothing you enter leaves your browser.

| Tool | What it does | Book reference | Online |
| --- | --- | --- | --- |
| [Timeline back-planner](tools/timeline-back-planner.html) | Enter a data lock point and get the date of every milestone in the 60-day model, with weekends and holidays flagged, a print view and CSV download. | Chapter 3 (3.2); Appendix C | https://abdu94-hash.github.io/dsur-workbench/tools/timeline-back-planner.html |
| [QC checklist](tools/qc-checklist.html) | Appendix B item by item, five high-yield checks first; mark each item, add comments and print a dated record. | Chapter 15; Appendix B | https://abdu94-hash.github.io/dsur-workbench/tools/qc-checklist.html |

The online addresses work once GitHub Pages is enabled for this repository.
