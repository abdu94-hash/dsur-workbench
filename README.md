# DSUR Workbench

Companion tools, Word and Excel templates, and a fully worked mock DSUR for the Selim Medical Press manual on writing **Development Safety Update Reports** under ICH E2F.

**Author:** Dr. Hafez Selim, MD, PhD · **Publisher:** [Selim Medical Press](https://abdu94-hash.github.io/selim-medical-press/)

> **Status:** under construction, alongside the book. The folder layout below is final; files are added as they are completed. See each folder's README for what is ready.

## What's here

| Folder | Contents | Status |
| --- | --- | --- |
| [`worked-example/`](worked-example/) | A complete mock DSUR for Case B (Word), its data workbook (Excel), and an annotated weak-draft version | In progress |
| [`templates/`](templates/) | Annotated DSUR shell: every E2F section with guidance text and "nothing to report" wording (Word) | Planned |
| [`cases/`](cases/) | The six fictional case cards used throughout the book (Word) | **Ready** |
| [`tools/`](tools/) | Interactive browser tools (HTML), published on GitHub Pages | Planned |
| `ch01/` … `ch17/` | Each chapter's templates, worked answers and links to its tools | Planned |
| [`UPDATES.md`](UPDATES.md) | Regulatory changes since publication | Live |
