# DSUR field guide

A free, interactive companion to *Writing the DSUR*. Open it online at <https://abdu94-hash.github.io/dsur-workbench/guide/>, or download this folder and open `index.html` in any modern browser.

| Page | What it gives you |
| --- | --- |
| Section pages (Title page to Appendices) | The point of the section, the question its reviewer asks, and how much detail it needs in early development, late development and for a marketed drug |
| Chapter pages (1 to 17) | Learning objectives, the most common failure, the five take-home messages, and a four-question self-check with the reasoning behind each answer |
| Detail by program stage | The whole stage table on one page |
| Companion files | Links to the tools, templates, case files, worked example and chapter folders |

Self-check scores stay in your own browser's storage. The full section blueprints, with model wording and nothing-to-report text, are in Appendix A of the book.
