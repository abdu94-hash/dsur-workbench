# Interactive tools

Single-file browser tools. Each runs offline: download the HTML file and open it in any modern browser, or use the online copy. Nothing you enter leaves your browser.

| Tool | What it is for | Book reference | Online (once GitHub Pages is enabled) |
| --- | --- | --- | --- |
| [Timeline back-planner](timeline-back-planner.html) | Enter a data lock point; get the date of every milestone in the 60-day model, with weekends and holidays flagged, adjustable day offsets, checks, a print view and CSV download. | Chapter 3 (3.2); Appendix C.1, C.2 | [tools/timeline-back-planner.html](https://abdu94-hash.github.io/dsur-workbench/tools/timeline-back-planner.html) |
| [QC checklist](qc-checklist.html) | Appendix B item by item, five high-yield checks first: mark each Pass, Issue or N/A with a comment, see summary counts, and print a dated record with reviewer and DSUR identifier; CSV download. | Chapter 15; Appendix B | [tools/qc-checklist.html](https://abdu94-hash.github.io/dsur-workbench/tools/qc-checklist.html) |

The tools keep your last entries in your own browser's storage, where available, so a page can be closed and reopened. Clear them with the tool's reset or clear button.
